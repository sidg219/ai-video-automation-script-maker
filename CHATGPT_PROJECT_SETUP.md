# ChatGPT Project setup

1. Create a new ChatGPT Project.
2. Add SYSTEM_PROMPT.md as the project instructions, or paste its contents into the project instructions field.
3. Upload templates/video-production-output.md and templates/videosly-handoff.md as project files.
4. Start a new chat in the project with a theme, for example: “Create a 90-second video teaching polite disagreement in a workplace meeting.”
5. Upload character/reference images when visual consistency matters.
6. Ask for revisions by scene ID rather than regenerating the whole brief.

As of November 2026, new custom GPT creation is unavailable on personal ChatGPT accounts. A Project is the practical reusable alternative unless your workspace provides GPT creation or you are editing an eligible existing GPT.
