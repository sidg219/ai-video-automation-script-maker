# AI Video Automation Script Maker

A reusable workflow package for turning a theme into a production-ready video script for manual VideoExpress work, plus a concise Videosly handoff for quick shorts.

The output is one detailed Markdown document containing the full concept, narration/dialogue, scene map, scene-by-scene image prompts, and matching image-to-multishot VideoExpress prompts. A final Videosly brief is included for rapid short-video creation once the user supplies the required theme, format and media details.

## Default request

Provide only a theme or idea. The workflow develops the audience, format, hook, story structure, narration, visual style, scene prompts and production notes. Ask only for information that materially changes the result.

## Output

- Video concept and audience
- Full script and narration
- Scene timing and continuity
- Detailed image prompt for every scene
- Immediately paired VideoExpress multishot prompt
- Captions, sound and edit notes
- Short Videosly handoff brief

## Add to ChatGPT

Use the files in a ChatGPT Project as its instructions and reference material. New custom GPT creation is currently unavailable on personal ChatGPT accounts; existing GPT editing depends on account eligibility. See the official OpenAI documentation linked in the project handoff notes.

This workflow is an original customization inspired by the user’s requested “10,000 Hours into AI Video Automation” pattern; the linked GPT’s private configuration was not publicly readable.
